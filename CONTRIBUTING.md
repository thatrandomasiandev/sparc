# Contributing

This is currently a **solo research project**. External PRs are not the focus yet.

If you are collaborating (advisor, lab mate):

1. Open an issue before large changes.
2. Keep `PROBLEM.md` / `EXPERIMENTS.md` ahead of code.
3. Every experiment run must leave `meta.json` + `metrics.json`.
4. Do not commit large binaries, secrets, or raw datasets — point at `data/` conventions instead.
5. Run `make test` before asking for review.
