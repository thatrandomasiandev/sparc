# Contributing

SPARC is a solo research/engineering project right now. There is no team process yet — just one maintainer, one roadmap, and a strict phase schedule in `ROADMAP.md`.

## Before you change anything

1. Read `ROADMAP.md` and confirm your change fits the **current phase**.
2. **Phase 0–1:** documentation and design only. No SPARC algorithm code.
3. **Phase 2+:** package subpackages (`env/`, `reward_model/`, etc.) appear when the roadmap says so (Week 8).

## If you are future-me (or a collaborator later)

- Open an issue using the templates in `.github/ISSUE_TEMPLATE/` before large changes.
- Keep commits small and tied to a single roadmap task.
- Do not pin dependencies in `pyproject.toml` until Phase 2 Week 8 — that is intentional.

## Pull requests

Not expected during Phase 0. If this repo goes public or adds collaborators, revisit this file.
