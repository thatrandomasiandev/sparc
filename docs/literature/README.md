# Reading notes

Drop per-paper notes here (`docs/literature/<author-year>.md`). Keep each note short:

1. **Claim** — what they say they contribute  
2. **Evidence** — what they actually measured  
3. **Assumptions** — what would break outside their lab/setting  
4. **Steal / avoid** — one idea to reuse, one pitfall to avoid  
5. **Cite as** — BibTeX key in `paper/references.bib`
